# 🧪 Lab Sample Data Analysis (Pandas + Python)

This project analyzes mock lab data for a chemical testing environment using Python, Pandas, and Seaborn. It simulates sample parameters like:

- TDS (mg/L)
- pH
- Free Chlorine
- Oil & Grease

The notebook performs basic exploration, time-series visualization, and location-based comparison of sample data.

## 📂 Dataset

- `sample_lab_data.csv` — mock lab sample data generated with realistic values

## 📊 Visuals

| Metric                      | Chart Type   |
|----------------------------|--------------|
| TDS over time              | Line Chart   |
| Oil & Grease distribution  | Boxplot      |
